🚀 AI Email Response Assistant
An intelligent full-stack solution designed to streamline email communication. This project features a Spring Boot backend integrated with Google Gemini AI, a React web dashboard, and a Chrome Extension that injects AI capabilities directly into the Gmail interface.

🛠️ Project Structure
This repository is organized as a monorepo:

/email-writer-sb: Spring Boot Backend (Java 17). Handles AI prompt engineering and communication with Gemini API.

/email-writer-react: Modern Web Frontend built with React for standalone email generation.

/email-writer-ext: Chrome Extension that scrapes email content from Gmail and provides an "AI Reply" button.
